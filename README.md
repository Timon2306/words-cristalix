# MC Words Overlay

Компактный HUD-оверлей для мини-игры «Слова» в Minecraft. Смотрит на вопрос на экране или в чате и предлагает до пяти подходящих слов.

## Как запустить

1. Скачайте `MC-Words-Overlay-Portable-x64.zip` из [Releases](https://github.com/Timon2306/words-cristalix/releases).
2. Распакуйте в любую папку.
3. Запустите `mc-words-overlay.exe`.

Установка не нужна. Настройки и ключи сохраняются автоматически.

Нужен Windows 10/11. Если SmartScreen покажет предупреждение — «Подробнее» → «Выполнить в любом случае».

## Настройка

Откройте настройки оверлея, выберите провайдера и вставьте свой API-ключ. Ключ можно получить в личном кабинете провайдера.

## Горячие клавиши

| Клавиши | Действие |
| :--- | :--- |
| `Alt + Q` | Захватить область с вопросом |
| `Alt + 1` … `Alt + 5` | Выбрать слово |
| `Alt + H` | Скрыть / показать оверлей |

По умолчанию слово копируется в буфер обмена. Автоотправка в чат выключена — её можно включить в настройках. Все сочетания клавиш тоже меняются.

## Точность ответов

Приложение не гарантирует 100% точность. На результат могут влиять нестандартные шрифты и полупрозрачные фоны текстур-паков, частицы, особенности словаря мини-игры и тайминги ответа нейросети. Проверяйте слово перед отправкой.
