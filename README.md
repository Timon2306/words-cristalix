# MC Words Overlay

Компактный HUD-оверлей для мини-игры «Слова» в Minecraft. Смотрит на вопрос на экране или в чате и предлагает до пяти подходящих слов.

## Установка

В релизе два файла:

- **`MC-Words-Overlay-Setup-x64.exe`** — установщик (рекомендуется). Запустите и следуйте инструкциям. Если в системе нет WebView2, установщик поставит его сам.
- **`MC-Words-Overlay-Portable-x64.exe`** — портативная версия. Один файл, установка не нужна; настройки и ключи хранятся в профиле Windows. На Windows 10/11 WebView2 уже есть.

Скачать: [Releases](https://github.com/Timon2306/words-cristalix/releases). Если SmartScreen покажет предупреждение — «Подробнее» → «Выполнить в любом случае».

## Настройка

Откройте настройки оверлея, выберите провайдера и вставьте свой API-ключ. Ключ можно получить в личном кабинете провайдера.

## Режимы

**Режим скриншота (рекомендуется).** Вопрос считывается с экрана. Используйте именно его.

**Режим логов Cristalix (не рекомендуется).** Вопрос берётся из файла логов. Он менее стабилен и может пропускать вопросы — включайте только если скриншот почему-то не подходит.

По умолчанию включён режим скриншота.

## Горячие клавиши

| Клавиши | Действие |
| :--- | :--- |
| `Alt + Q` | Захватить область с вопросом |
| `Alt + 1` … `Alt + 5` | Выбрать слово |
| `Alt + H` | Скрыть / показать оверлей |

По умолчанию слово копируется в буфер обмена. Автоотправка в чат выключена — её можно включить в настройках. Все сочетания клавиш тоже меняются.

## Точность ответов

Приложение не гарантирует 100% точность. На результат могут влиять нестандартные шрифты и полупрозрачные фоны текстур-паков, частицы, особенности словаря мини-игры и тайминги ответа нейросети. Проверяйте слово перед отправкой.
